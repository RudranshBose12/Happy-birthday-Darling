# Birthday celebration sounds

Add your own audio files to this folder with these exact names:

- `Birthday Sound Effect.mp3` — the birthday sound/music that plays once after the candles are blown out.
- `Confetti Pop.mp3` — the short confetti-pop sound that plays when the confetti starts.

These files are used only by the Chapter 1 candle-blow celebration. Keep the filenames and capitalization exactly as shown.
