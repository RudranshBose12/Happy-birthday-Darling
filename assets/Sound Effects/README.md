# Sound Effects

Upload the three audio files into this folder using these exact filenames:

- `Click Button.mp3` — plays on ordinary website button clicks.
- `Star Connection.mp3` — plays each time a star is connected in Chapter 6.
- `Completion Melody.mp3` — plays when a chapter's Continue / next button is clicked.

Keep the spaces and capitalization exactly as shown. The website references these files at:

- `assets/Sound Effects/Click Button.mp3`
- `assets/Sound Effects/Star Connection.mp3`
- `assets/Sound Effects/Completion Melody.mp3`

You can use another audio extension if needed, but the matching paths in `index.html` must then be updated too.
